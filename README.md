## 📈 Daily Workflow

For each day, I aim to follow a simple process:

```text
Learn → Practice → Build → Document → Commit
```

1. Learn a new concept or strengthen an existing one.
2. Solve problems related to the concept.
3. Write and test code.
4. Document what I learned.
5. Commit my progress to GitHub.

## 💡 Rules of the Challenge

> **The goal isn't to be perfect. The goal is to not quit.**

1. Code every day.
2. Make at least one meaningful contribution to the repository each day.
3. Don't just copy code — understand it.
4. Document mistakes and lessons.
5. Keep moving even when progress feels slow.
6. Finish the 21 days.

---

## 🌱 Why I'm Doing This

Programming is a skill built through repetition.

This challenge is less about completing 21 days and more about developing a long-term habit of **learning, building, and improving consistently**.

By the end of these 21 days, I want this repository to be a record of not only what I built, but also how much I improved.
